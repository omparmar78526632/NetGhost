What is NetGhost? 🔗

NetGhost is a controlled laboratory project demonstrating how framed encrypted data can be represented through selected packet fields or timing behavior in IPv4 network traffic.

ⓘ This interface is intended for controlled academic experimentation and measurement.

Methods 🔗

IP-ID Header Embedding

Embeds framed data into the IPv4 Identification field for controlled packet-level experiments.

Temporal IPD

Encodes bits using controlled packet inter-arrival timing and measured traffic profiles.

Security Boundary 🔗

🔒 AES-256-GCM

AES-256-GCM provides authenticated encryption for the experimental payload and supports verification during receiver decoding.

This interface does not claim real-world firewall or DPI bypass.

Traffic Baseline Modeling

Baseline packet timing is measured from laboratory traffic to establish reference behavior for controlled comparisons.

GMM Timing Profile

A Gaussian Mixture Model represents multiple timing components and produces a configurable statistical profile.

Packet Framing

Encrypted payloads are organized into identifiable fragments so the receiver can validate ordering and reconstruct the message.

Receiver Decoding

The receiver captures traffic, identifies framed data, reassembles fragments, authenticates the ciphertext and decrypts the result.

Future Work

Future experimentation may evaluate additional laboratory channels, timing models and measurement techniques while preserving the controlled-environment boundary.
